### analises_criticas
Espaço para o grupo documentar a avaliação do cenário de descarte em cada município.


| Campo | Tipo / Descrição |
| :--- | :--- |
| **id** | Identificador único da análise |
| **cidade** | Cidade do Alto Vale analisada |
| **facilidade** | Pontos positivos encontrados no município |
| **dificuldades** | Barreiras observadas no descarte local |
| **divulgação** | Como a prefeitura/órgãos divulgam a coleta (Ruim/Média/Boa) |
| **melhorias** | Sugestões propostas pelo grupo para o município |
